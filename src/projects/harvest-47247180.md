# Strapi <Badge type="tip" text="Strapi/React" />

## Introduction

This project is a web application developed to support the management of announcements and user interactions.
The objective of the project was to design and implement a structured full-stack application
using a headless CMS backend to manage content, users, and moderation workflows. The project focused on scalable
architecture, secure authentication, and dynamic frontend-backend communication.

## Technologies Used

- Strapi
- React
    - strapi-client
- JWT Authentication
- REST API

## Description

The application consists of a Strapi backend that serves as a headless CMS for managing content, user accounts, and
moderation processes. The frontend is built with React, providing a user-friendly interface for interacting with the
backend services. The application allows users to create and manage announcements, while administrators can moderate
content and manage user accounts.

This was an opportunity for me to explore the capabilities of Strapi as a headless CMS instead of WordPress.

## Operational Competencies Acquired

During the development of this project, I defined the project requirements and objectives and search for the best tools
to create a headless website and have a secure and easy to setup login for all users.

I also had to do research on the topic of deployment, as we had multiple option to deploy the application. 
A decision was also needed to take to moderate content, as we had to choose between a manual moderation process before publication or an automatic process with a report system for users to report inappropriate content.
