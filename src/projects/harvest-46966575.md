# Site vitrine WordPress Headless avec GraphQL

## What is the project purpose ?

This project consists of developping a showcase website using WordPress as a headless CMS and GraphQL for data fetching. 
The main goal is to create a modern and efficient website that can easily manage content through WordPress while 
providing a seamless user experience on the front end.

## How did I do it

To achieve this, I set up a WordPress instance and configured it to serve as a headless CMS. I then implemented GraphQL to fetch data from WordPress, allowing for more flexible and efficient data retrieval. On the front end, I used React to build a dynamic and responsive user interface that interacts with the GraphQL API to display content.

## technical concepts

In a traditional architecture, WordPress manages both:

- Content
- HTML rendering

In this project, WordPress is used solely as a content management system, while rendering is performed by an independent React application.
The WPGraphQL plugin allows content to be exposed as a GraphQL API, enabling:

- Precise queries
- Better data optimisation
- A more modern architecture

## Operational Competencies Acquired

During the development of the headless website, I identified the dependencies between the WordPress backend, the GraphQL API layer, and the React frontend, and selected an appropriate decoupled platform architecture. I defined a layered model separating content management, API communication, and presentation logic, while considering security requirements and platform constraints. I selected the necessary resources according to best practices and validated architectural decisions for consistency.

I analyzed structured data from WordPress before integrating it into the frontend, ensured data accuracy and coherence, defined suitable test cases, structured and normalized the data model, and represented it clearly within the application.

For the user interface, I created interface mockups and prototypes, identified usability issues, verified technical feasibility, and implemented functional, dynamic UI components connected to the headless architecture.
